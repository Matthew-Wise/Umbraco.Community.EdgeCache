Edge Cache for Umbraco — purges CDN / edge caches when content changes. Pair the core package with one of the provider packages (`Umbraco.Community.EdgeCache.CloudFlare` or `Umbraco.Community.EdgeCache.AzureFrontDoor`) to target your CDN.
